Embeddable Widget Demo

🍽️ College Canteen Website

Welcome to the college canteen portal! This page demonstrates the embeddable AI chatbot widget floating in the bottom-right corner.

✨ Zero-Hallucination Canteen Assistant
• Answers factual questions about prices, timing, ingredients, and spice level directly from SQLite.
• Recommends top 3 dishes using content-based vector cosine similarity.
• Powered by Groq's llama-3.3-70b-versatile with graceful secondary fallback.

How to Embed on Any Website:

<!-- Add this single tag before </body> on any website -->
<script 
  src="http://localhost:3000/widget.js" 
  data-api="http://localhost:8000/api/canteen/chat">
</script>

👉 Click the circular dish bubble (🍽️) in the bottom-right corner to test the widget!
